# Plan 02-03: Native Canvas Encoders, Conversion Pipeline Integration & Offscreen Document Handler

## Objective
Integrate native Canvas encoders (PNG, JPEG, WebP, AVIF), SVG passthrough, and pure-JS encoders into a single unified conversion pipeline (`converter.ts`). Connect the conversion engine to the offscreen document message dispatcher (`offscreen.ts`) and enhance the background service worker CORS-bypass fetcher, completing Phase 2 image conversion capabilities across all 9 target formats.

## Requirements Addressed
- **CONV-01**: Client-side conversion from raw image blob/URL to PNG format with alpha preservation.
- **CONV-02**: Client-side conversion to JPEG format with configurable compression quality slider (1-100%) and automatic white background fill for transparent alpha channels.
- **CONV-03**: Client-side conversion to WebP format with configurable quality.
- **CONV-04**: Client-side conversion to AVIF format with native browser encoder.
- **CONV-09**: Native SVG extraction and preservation for inline `<svg>` and `*.svg` images.
- **CONV-10**: Background fetch with extension host permissions bypasses webpage CORS restrictions for cross-origin image decoding.

## Tasks

### 1. Implement Native Canvas Encoders (`src/offscreen/encoders/native.ts`)
- Implement `encodeNative(canvas: HTMLCanvasElement | OffscreenCanvas, format: 'png' | 'jpeg' | 'webp' | 'avif', quality?: number): Promise<Blob>`:
  - Map target format to standard MIME type (`image/png`, `image/jpeg`, `image/webp`, `image/avif`).
  - Pass sanitized quality parameter (clamped between `0.01` and `1.0`) for JPEG, WebP, and AVIF.
  - Implement fallback handling for older Chromium versions if AVIF encoding is unsupported.

### 2. Implement SVG Passthrough & Serializer (`src/offscreen/encoders/svg.ts`)
- Implement `encodeSvg(source: ImageSource): Promise<Blob>`:
  - If input is raw SVG string or SVG URL: sanitize XML markup, ensure `xmlns="http://www.w3.org/2000/svg"` and `viewBox` attributes are present.
  - Return `Blob` with MIME type `image/svg+xml`.

### 3. Build Unified Image Converter Engine (`src/offscreen/converter.ts`)
- Implement `convertImage(request: ConvertImageRequestMessage): Promise<ConversionResult>`:
  - Parse input image source via `ImageLoader` / `SvgLoader`.
  - Check target format:
    - `svg`: If source is SVG, pass through directly via `encodeSvg`; otherwise rasterize or return error if converting raster to SVG.
    - `png`: Render to canvas with transparency -> `encodeNative(canvas, 'png')`.
    - `jpeg`: Render to canvas with solid background fill (default `#FFFFFF`) -> `encodeNative(canvas, 'jpeg', quality)`.
    - `webp`: Render to canvas (alpha preserved) -> `encodeNative(canvas, 'webp', quality)`.
    - `avif`: Render to canvas (alpha preserved) -> `encodeNative(canvas, 'avif', quality)`.
    - `bmp`: Render to canvas (solid background fill if transparent) -> `encodeBmp(imageData)`.
    - `gif`: Render to canvas -> `encodeGif(imageData)`.
    - `ico`: Render multi-res icons -> `encodeIco(canvas)`.
    - `pdf`: Render to canvas -> `encodePdf(canvas)`.
  - Convert output `Blob` to base64 Data URL and compute byte length, width, and height.
  - Return comprehensive `ConversionResult`:
    ```typescript
    export interface ConversionResult {
      dataUrl: string;
      mimeType: string;
      byteLength: number;
      width: number;
      height: number;
    }
    ```

### 4. Wire Offscreen Document Dispatcher (`src/offscreen/offscreen.ts`)
- Update `handleConvertRequest` to call `convertImage(request)`.
- Implement robust error handling, memory cleanup, and detailed error messages on conversion failures.

### 5. Validate Background Service Worker Fetch & Download Pipeline (`src/background/service-worker.ts`)
- Ensure `FETCH_IMAGE_REQUEST` handles all image content types properly with extension CORS bypass privileges.
- Ensure `CONVERT_IMAGE_REQUEST` forwards to offscreen document and returns converted Data URL.

### 6. Write Comprehensive Test Suite (`tests/converter.test.ts`)
- Test conversion pipeline across all 9 formats (`png`, `jpeg`, `webp`, `avif`, `bmp`, `gif`, `ico`, `pdf`, `svg`).
- Test alpha background fill on transparent images for JPEG and BMP (verify background is white, not black).
- Test quality slider parameter propagation for lossy formats (JPEG, WebP, AVIF).
- Test SVG preservation and rasterization workflows.
- Test error handling for invalid or corrupted image data.

## Verification
- Run `npm run test` and verify 100% of conversion tests pass.
- Run `npm run build` to verify clean bundle generation in `dist/`.
- Verify memory cleanup (no dangling object URLs or unreleased canvases).
