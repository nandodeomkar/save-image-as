# Plan 02-02: Pure-JS Format Encoders (BMP, Windows Multi-Resolution ICO, PDF & GIF)

## Objective
Implement specialized client-side binary encoders for image and document formats that do not have native Canvas `toBlob` support in Chromium: pure-JS Windows Bitmap (BMP), Windows multi-resolution icon container (ICO), single-image Portable Document Format (PDF), and static Graphics Interchange Format (GIF).

## Requirements Addressed
- **CONV-05**: Pure-JS client-side conversion to 24/32-bit Windows BMP format.
- **CONV-06**: Client-side conversion to single-frame GIF format.
- **CONV-07**: Pure-JS multi-resolution Windows ICO icon generator (16x16, 32x32, 48x48, 256x256).
- **CONV-08**: Client-side single-image PDF document generation.

## Tasks

### 1. Implement Pure-JS Windows BMP Encoder (`src/offscreen/encoders/bmp.ts`)
- Zero-dependency binary encoder taking `ImageData` (RGBA) and generating valid `.bmp` file bytes:
  - Support standard 24-bit uncompressed RGB and 32-bit uncompressed RGBA.
  - Construct 14-byte `BITMAPFILEHEADER`:
    - Magic number: `0x4D42` (`'BM'`)
    - File size in bytes
    - Reserved: 0
    - Data offset: 54 bytes (14 header + 40 DIB header)
  - Construct 40-byte `BITMAPINFOHEADER`:
    - Header size: 40
    - Width and Height (positive integer for bottom-up raster)
    - Color planes: 1
    - Bits per pixel: 24 (or 32)
    - Compression: 0 (`BI_RGB` uncompressed)
    - Image size: row size × height
    - Pixels per meter: 2835 (~72 DPI)
  - Row padding: BMP requires each scanline to be a multiple of 4 bytes (`padding = (4 - (width * 3) % 4) % 4`).
  - Pixel formatting: Convert RGBA to BGR format in bottom-up row order.
  - Return `Blob` (`image/bmp`) and `Uint8Array`.

### 2. Implement Windows Multi-Resolution ICO Encoder (`src/offscreen/encoders/ico.ts`)
- Multi-resolution icon container generator supporting standard Windows icon sizes: `16x16`, `32x32`, `48x48`, and `256x256` (or adaptive subsets based on original image size):
  - Scale source image to each target resolution using canvas downsampling.
  - Encode each sub-image as a PNG chunk (modern ICO standard supported by Windows Vista/7/10/11 and all browsers).
  - Construct `ICONDIR` header (6 bytes):
    - `idReserved`: 0 (2 bytes)
    - `idType`: 1 for ICO (2 bytes)
    - `idCount`: Number of image entries (2 bytes)
  - Construct `ICONDIRENTRY` array (16 bytes per entry):
    - `bWidth`: Image width (0 for 256px)
    - `bHeight`: Image height (0 for 256px)
    - `bColorCount`: 0
    - `bReserved`: 0
    - `wPlanes`: 1
    - `wBitCount`: 32
    - `dwBytesInRes`: Byte length of PNG data chunk
    - `dwImageOffset`: Byte offset from file start to PNG data chunk
  - Assemble contiguous binary buffer with all directory entries followed by PNG payloads.
  - Return `Blob` (`image/x-icon`).

### 3. Implement Single-Image PDF Container (`src/offscreen/encoders/pdf.ts`)
- Client-side single-page PDF generator wrapping the image into a clean PDF document using `jspdf`:
  - Determine optimal PDF page orientation (portrait vs landscape) and page dimensions matching the image's exact aspect ratio.
  - Insert image using high-quality JPEG or PNG compression.
  - Fit image edge-to-edge or with proportional margins.
  - Return `Blob` (`application/pdf`).

### 4. Implement Single-Frame GIF Encoder (`src/offscreen/encoders/gif.ts`)
- Static GIF encoder using `omggif`:
  - Extract RGBA pixels from `ImageData`.
  - Perform 256-color palette quantization (with transparency index detection for alpha pixels).
  - Construct GIF data stream with `GifWriter`:
    - Screen width and height
    - Color palette (global color table)
    - Graphic control extension with transparency index
    - Compressed frame data
  - Return `Blob` (`image/gif`).

### 5. Export Unified Encoders Index (`src/offscreen/encoders/index.ts`)
- Central barrel file exporting `encodeBmp`, `encodeIco`, `encodePdf`, and `encodeGif`.

### 6. Write Unit Tests
- `tests/bmp-encoder.test.ts`: Test BMP magic bytes (`BM`), header sizes, 24-bit/32-bit row padding, bottom-up row ordering.
- `tests/ico-encoder.test.ts`: Test ICO header values (`idCount`), directory entry offsets, PNG payload integrity.
- `tests/pdf-encoder.test.ts`: Test PDF magic header (`%PDF-`), valid page structure, output blob MIME type.
- `tests/gif-encoder.test.ts`: Test GIF header (`GIF89a`), color table size, valid encoded frame stream.

## Verification
- Run `npm run test` and verify 100% of binary encoder tests pass.
- Verify generated BMP, ICO, PDF, and GIF byte structures conform strictly to file format specifications.
