# Plan 02-01: Canvas & OffscreenCanvas Rendering Engine with Alpha Blending & SVG Loader

## Objective
Implement the core image loading and canvas rendering infrastructure for the offscreen document. Provide robust image decoding across multiple input formats (URLs, Data URLs, Blob buffers, raw SVG markup), dimension extraction and scaling, and alpha-channel background fill logic (to prevent black box artifacts when exporting transparent images to opaque formats like JPEG and BMP).

## Requirements Addressed
- **CONV-01**: Client-side conversion from raw image blob/URL to PNG format with alpha preservation.
- **CONV-02**: Client-side conversion to JPEG format with configurable compression quality slider (1-100%) and automatic white background fill for transparent alpha channels.
- **CONV-09**: Native SVG extraction and preservation for inline `<svg>` and `*.svg` images.
- **CONV-10**: Background fetch with extension host permissions bypasses webpage CORS restrictions for cross-origin image decoding.

## Tasks

### 1. Implement Robust Image Loader (`src/offscreen/image-loader.ts`)
- Support loading image sources from:
  - Remote/local URLs (`http:`, `https:`, `blob:`, `chrome-extension:`)
  - Base64 Data URLs (`data:image/...;base64,...`)
  - Binary ArrayBuffers / Blobs
  - Raw SVG markup strings
- Implement `loadImage(source: ImageSource): Promise<LoadedImage>`:
  - Prefer `createImageBitmap` for high-performance off-main-thread decoding when supported.
  - Fallback to `HTMLImageElement` with `crossOrigin = "anonymous"` and `img.decode()` for maximum SVG and format compatibility.
  - Automatically manage Blob URL creation (`URL.createObjectURL`) and cleanup (`URL.revokeObjectURL`) to prevent memory leaks.
  - Extract `naturalWidth`, `naturalHeight`, and aspect ratio.

### 2. Implement SVG Parsing & Vector Rasterizer (`src/offscreen/svg-loader.ts`)
- Implement `parseSvg(svgString: string): SvgInfo`:
  - Extract or compute intrinsic dimensions from `width`, `height`, and `viewBox` attributes.
  - If dimensions are missing, use default fallback dimensions (e.g. 800x800) maintaining viewBox aspect ratio.
  - Sanitize and format SVG content into valid standalone XML with `xmlns="http://www.w3.org/2000/svg"`.
- Implement `rasterizeSvg(svgString: string, targetWidth?: number, targetHeight?: number): Promise<HTMLImageElement | ImageBitmap>`:
  - Render SVG markup onto high-resolution canvas maintaining sharp vector edges.

### 3. Implement Canvas Rendering & Alpha Blending Engine (`src/offscreen/canvas-renderer.ts`)
- Create canvas rendering utilities (`HTMLCanvasElement` and `OffscreenCanvas`):
  - Setup 2D rendering context with high-quality image smoothing (`imageSmoothingQuality = "high"`).
- Implement solid background fill logic:
  - When converting to formats that lack alpha support (JPEG, BMP) or when explicit background color is requested:
    - Pre-fill canvas with the user's chosen background color (default `#FFFFFF` white) using `ctx.fillRect(0, 0, width, height)`.
    - Composite image over background using `source-over` blend mode.
  - When converting to alpha-supporting formats (PNG, WebP, AVIF, ICO, GIF):
    - Preserve complete transparency unless explicit background color is provided.
- Implement dimension scaling helper:
  - `scaleDimensions(origWidth: number, origHeight: number, options?: ScaleOptions): { width: number; height: number }`
  - Support proportional scaling and max dimension limits while preserving aspect ratio.
- Return structured canvas wrapper:
  ```typescript
  export interface RenderedCanvas {
    canvas: HTMLCanvasElement | OffscreenCanvas;
    ctx: CanvasRenderingContext2D | OffscreenCanvasRenderingContext2D;
    width: number;
    height: number;
    getImageData(): ImageData;
    toBlob(mimeType: string, quality?: number): Promise<Blob>;
    toDataURL(mimeType: string, quality?: number): string;
  }
  ```

### 4. Unit Tests (`tests/canvas-renderer.test.ts`)
- Test image loading abstractions with simulated bitmaps and mock image decoders.
- Test SVG parsing with various `<svg>` headers (with/without viewBox, explicit width/height).
- Test alpha background fill logic: verify transparent pixels composite cleanly onto white/custom backgrounds.
- Test dimension scaling and aspect ratio calculations.
