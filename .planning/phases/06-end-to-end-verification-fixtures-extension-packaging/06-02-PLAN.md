# Plan 06-02: Extension Packaging, Manifest Validation & Release Artifact Generation

## Objective
Implement an automated Node.js packaging and validation script that inspects the production build (`dist/`), validates the MV3 manifest and required assets, tests bundle integrity, creates a clean `.zip` distribution artifact, and completes final roadmap milestones.

## Requirements Addressed
- **ARCH-01**: Extension is packaged under Chrome Extensions Manifest V3 specification with appropriate permissions.
- **ARCH-04**: Modern build pipeline packages background, content, offscreen, and popup scripts into optimized bundles.

## Tasks
1. Create `scripts/package-extension.js`:
   - Validates `dist/manifest.json` against Chrome MV3 schema requirements.
   - Verifies presence of background worker, content script, offscreen HTML/JS, popup HTML/CSS/JS, and icons (16, 32, 48, 128px).
   - Verifies bundle sizes, CSP configuration, and permissions.
   - Packages `dist/` into `save-image-as-v1.0.0.zip` using Node's standard zip/archiver utility.

2. Update `package.json`:

3. Execute and verify:

   - Run `npm run build` -> Clean Vite build.
   - Run `npm run package` -> Generates production zip artifact.
