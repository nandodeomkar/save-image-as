# Plan 03-02: Shortcut Listener & Content Script IPC Integration

## Objective
Implement the 1-click keyboard modifier shortcut listener (Alt + Click / Option + Click) in the content script, wire DOM inspection into extension context-menu and quick-save flows, and integrate background service worker conversion + download coordination.

## Requirements Addressed
- **DOM-06**: Alt + Click (or customizable modifier) on any image triggers immediate 1-click download in the user's default format.

## Tasks

### 1. Update Shared IPC Types & Message Definitions (`src/utils/types.ts`)
- Add `QuickSaveImageRequestMessage` and response types for 1-click shortcut triggered downloads.
- Ensure `InspectElementRequestMessage` and `InspectElementResponseMessage` carry complete inspection payload (`InspectElementResult`).

### 2. Implement Shortcut Event Listener (`src/content/shortcut-handler.ts`)
- Listen to `click` events at the capturing phase (`window.addEventListener('click', handler, true)`).
- Check if the active modifier key (from settings: `alt`, `ctrl`, `shift`, default `alt`) is pressed during click:
  - Support cross-platform Option key on macOS (`e.altKey`).
- When modifier key is pressed:
  - Inspect clicked target element using `inspectElement(event.target)`.
  - If a valid image/asset is found:
    - Prevent default action (`e.preventDefault()`, `e.stopPropagation()`, `e.stopImmediatePropagation()`) to prevent navigation or default browser download.
    - Provide subtle visual feedback (e.g. temporary highlight outline or cursor ripple).
    - Send `QUICK_SAVE_IMAGE_REQUEST` to the background service worker with extracted image data and metadata.

### 3. Integrate Content Script Lifecycle (`src/content/inspector.ts`)
- Track `lastRightClickedElement` on `contextmenu` event.
- Handle `INSPECT_ELEMENT_REQUEST` from background worker / context menu click:
  - Call `inspectElement(lastRightClickedElement)`.
  - Return `InspectElementResult` with full metadata (`pageTitle`, `pageUrl`, `pageDomain`, `url`, `svgContent`, `canvasDataUrl`).
- Initialize shortcut listener with user settings.
- Listen for `SETTINGS_UPDATED` IPC message to dynamically update shortcut modifier and active settings without page reload.

### 4. Wire Background Quick-Save Workflow (`src/background/service-worker.ts`)
- Handle `QUICK_SAVE_IMAGE_REQUEST` in service worker:
  - Read user settings from `chrome.storage.sync` (default format, quality, filename template, background color).
  - Delegate image conversion to offscreen document (or native SVG download if SVG format).
  - Construct target filename and dispatch download via `chrome.downloads.download()`.
  - Return success/error status to caller.

### 5. Unit & DOM Tests (`tests/shortcut-handler.test.ts`)
- Test modifier key matching (`alt`, `ctrl`, `shift`).
- Test event prevention when modifier is active on an image.
- Test no-op when modifier is not pressed or clicked element is not an image.
- Test settings update dynamic refresh.

## Verification
- Run `npm test` to verify all shortcut and DOM tests pass.
- Run `npm run build` to verify clean extension bundling without errors.
