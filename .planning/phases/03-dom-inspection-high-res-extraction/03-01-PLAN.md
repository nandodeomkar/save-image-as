# Plan 03-01: DOM Element Inspector & High-Resolution Asset Extractor

## Objective
Build a robust DOM element inspection engine in the content script that accurately identifies and extracts images from any web page element: `<img>` tags with responsive `srcset` resolution ranking, `<picture>` elements with media queries/sources, CSS `background-image` declarations (including pseudo-elements and parent wrappers), HTML5 `<canvas>` elements, and inline `<svg>` graphics.

## Requirements Addressed
- **DOM-01**: Content script inspects right-clicked elements to identify `<img>`, `<picture>`, and `<source>` tags.
- **DOM-02**: `srcset` parser extracts the highest-resolution image source available based on width and pixel density descriptors.
- **DOM-03**: Detects and extracts CSS `background-image: url(...)` from container elements and CSS pseudo-elements.
- **DOM-04**: Captures raw image data from HTML5 `<canvas>` elements.
- **DOM-05**: Captures source markup from inline `<svg>` elements.

## Tasks

### 1. Implement Responsive `srcset` Parser (`src/content/srcset-parser.ts`)
- Parse complex `srcset` strings with width descriptors (`1200w`), pixel density descriptors (`2x`, `3x`), and default `1x`.
- Handle edge cases: commas in query parameters, URLs with encoded characters, and Data URLs.
- Implement candidate ranking algorithm:
  - `parseSrcset(srcset: string, baseUrl?: string): SrcsetCandidate[]`
  - `getHighestResolutionCandidate(srcset: string, fallbackSrc?: string, baseUrl?: string): string`
  - Rank candidates by effective pixel width (treating `Nx` as `N * viewport_width` or standard base width).
  - Return the highest-resolution URL resolved against document `baseUrl`.

### 2. Implement CSS Background Image Extractor (`src/content/css-background.ts`)
- Implement `extractCssBackgroundImage(element: Element): string | null`:
  - Inspect `window.getComputedStyle(element).backgroundImage`.
  - Also inspect pseudo-elements `::before` and `::after`.
  - Parse `url("...")`, `url('...')`, or `url(...)` syntax and strip gradients (`linear-gradient`, etc.).
  - If multiple background layers exist, extract the first valid image URL.
  - Traverse up ancestor tree (up to 3-4 levels) if current element is a transparent overlay covering a background container.

### 3. Implement SVG & Canvas Extractors (`src/content/svg-extractor.ts`, `src/content/canvas-extractor.ts`)
- `extractInlineSvg(element: Element): { svgContent: string; width?: number; height?: number } | null`:
  - If element is `<svg>` or a child of `<svg>` (e.g. `<path>`, `<g>`, `<circle>`), locate root `<svg>` element.
  - Clone SVG and ensure `xmlns="http://www.w3.org/2000/svg"` attribute is present.
  - Extract intrinsic width/height or viewBox dimensions.
  - Serialize using `XMLSerializer` or `outerHTML`.
- `extractCanvasData(element: Element): { dataUrl: string; width: number; height: number } | null`:
  - If element is `<canvas>`, obtain dimensions and export `toDataURL('image/png')`.
  - Handle tainted canvas security errors gracefully with informative error fallback.

### 4. Implement Comprehensive DOM Inspector (`src/content/dom-inspector.ts`)
- Implement `inspectElement(target: HTMLElement | Element | null): InspectElementResult | null`:
  - Inspect direct element and hierarchy:
    1. If `<img>`: check `srcset`, `currentSrc`, and `src`. If enclosed in `<picture>`, inspect all `<source>` children and choose highest resolution.
    2. If `<svg>` or inside `<svg>`: serialize SVG markup.
    3. If `<canvas>`: export data URL.
    4. If `<video>`: check `poster` attribute.
    5. If CSS `background-image` present on element or immediate parent/overlay: extract URL.
    6. If `<a>` wrapping an image or pointing directly to an image URL: extract link target.
  - Fallback overlay detection: use `document.elementsFromPoint(x, y)` to find hidden images beneath transparent click-shield divs.
  - Extract metadata: `naturalWidth`, `naturalHeight`, `altText`, `pageTitle`, `pageUrl`, `pageDomain`.

### 5. Unit & DOM Tests (`tests/srcset-parser.test.ts`, `tests/dom-inspector.test.ts`)
- Unit tests for `srcset-parser`: width descriptors, density descriptors, malformed strings, query params.
- DOM tests for `dom-inspector`:
  - Test standard `<img>` with `src` and `srcset`.
  - Test `<picture>` with multiple `<source>` tags.
  - Test CSS `background-image` extraction from div and pseudo-elements.
  - Test inline `<svg>` and deep SVG child targeting (`<path>`).
  - Test `<canvas>` export.
  - Test transparent overlay detection.
