# Plan 05-01: Popup Interface Markup, CSS Design System & Accessible Layout

## Objective
Build the HTML markup and CSS styling for the extension's popup dashboard. Create an intuitive, high-performance dark-themed UI matching modern browser extension standards with custom switches, format selector chips, quality sliders with live value tags, background color swatches, clickable filename token helper chips, and a live filename preview card.

## Requirements Addressed
- **UI-01**: Popup interface displays format checklist to enable/disable specific formats in the context menu.
- **UI-02**: Dropdown selector to choose the default format used for 1-click shortcut downloads.
- **UI-03**: Quality slider for lossy formats (JPEG, WebP, AVIF) with live percentage readout.
- **UI-04**: Filename template input with token preview and token helper chips.
- **UI-05**: Background fill color toggle (White / Black / Custom color picker) for formats lacking alpha channel.

## Tasks
1. Create `src/popup/popup.css`:
   - Design tokens: Slate dark palette, indigo/blue primary accents, emerald success indicators, surface elevations.
   - Clean custom-styled UI elements: toggle switches, range sliders with styled tracks/thumbs, segmented pills, chip buttons, dropdown selects, and color swatches.
   - Micro-animations: Smooth transitions for state toggles, hover effects, chip clicks, and toast notifications.
   - Responsive, overflow-safe layout sized cleanly for browser action popups (380px width).
2. Update `src/popup/popup.html`:
   - Header with icon, title, version, and sync status badge.
   - Shortcut & Quick Save section: Default format select (`<select id="default-format">`), Shortcut key select (`<select id="shortcut-modifier">`), and Notification toggle.
   - Context Menu Formats section: Format toggle grid (`<div id="formats-grid">`) for all 9 formats with descriptive metadata.
   - Quality Controls section: Sliders for JPEG, WebP, AVIF with live percentage badges.
   - Alpha Background Fill section: Preset buttons (White, Black) plus native `<input type="color">` swatch.
   - Filename Template section: Template input (`<input id="filename-template">`), token chip container (`<div id="token-chips">`), and live preview card (`<div id="filename-preview">`).
   - Footer with Reset button (`<button id="btn-reset">`) and live sync feedback.

## Verification
- Clean HTML semantic structure validating with zero console errors or broken styles.
- Bundles cleanly with `npm run build`.
