# Plan 05-02: Popup Settings State Controller, Real-time Sync & Automated Tests

## Objective
Implement the TypeScript state controller for the popup settings dashboard. Wire all UI controls (format checkboxes, default format selector, shortcut modifier, quality range sliders, color picker, and filename template) to `chrome.storage.sync` with instant debounced saves, clickable token chips inserting at cursor position, live filename preview, reset confirmation, and automated test coverage.

## Requirements Addressed
- **UI-01**: Popup interface displays format checklist to enable/disable specific formats in the context menu.
- **UI-02**: Dropdown selector to choose the default format used for 1-click shortcut downloads.
- **UI-03**: Quality slider for lossy formats (JPEG, WebP, AVIF) with live percentage readout.
- **UI-04**: Filename template input with token preview and token helper chips.
- **UI-05**: Background fill color toggle (White / Black / Custom color picker) for formats lacking alpha channel.
- **UI-06**: Real-time persistence and synchronization of all settings via `chrome.storage.sync`.

## Tasks
1. Implement `src/popup/popup.ts`:
   - Initialize controller on DOMContentLoaded: load settings with `getSettings()`.
   - Populate dynamic format toggle cards from `FORMAT_REGISTRY`.
   - Synchronize DOM inputs with loaded settings values:
     - Checkbox states for `enabledFormats` (with constraint preventing unchecking all formats).
     - Select value for `defaultFormat` and `shortcutModifier`.
     - Slider values and text badges for `jpegQuality`, `webpQuality`, `avifQuality`.
     - Color inputs and active swatch styling for `backgroundColor`.
     - Input value and preview display for `filenameTemplate`.
     - Checkbox state for `notifyOnSuccess`.
   - Event listeners for two-way binding and instant storage synchronization via `saveSettings()`.
   - Live Token Helper: Clicking a token chip inserts the token at the input's current cursor position / selection and refreshes the live filename preview using `previewFilename()`.
   - Real-time settings listener via `onSettingsChanged()` to sync popup if changed externally.
   - Reset button action that restores defaults and refreshes UI.
   - Visual saved indicator / toast confirming persistence.
2. Create automated tests in `tests/popup.test.ts`:
   - Test initial loading and rendering of settings into DOM elements.
   - Test toggling format checkboxes updates `enabledFormats` in storage.
   - Test minimum enabled formats constraint (cannot disable all formats).
   - Test updating default format and shortcut modifier saves correctly.
   - Test moving quality sliders updates percentage readout and saves decimal quality (e.g. 80 -> 0.8).
   - Test selecting background color presets and custom color picker updates `backgroundColor`.
   - Test typing filename template and clicking token chips updates preview and saves template.
   - Test reset button restores default configuration.

## Verification
- `npm test` runs and all popup tests pass along with existing test suite.
- `npm run typecheck` and `npm run build` pass with zero errors.
