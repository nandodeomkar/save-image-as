# Plan 01-02: Background Service Worker Lifecycle, Offscreen Manager & Typed IPC Bridge

## Objective
Implement the background service worker lifecycle management, offscreen document manager (with automated creation, reuse, mutex locking, and heartbeat), and a strongly-typed Inter-Process Communication (IPC) bridge between the service worker, offscreen document, content scripts, and popup.

## Requirements Addressed
- **ARCH-02**: Background service worker manages extension lifecycle, context menu events, message dispatching, and offscreen document creation.
- **ARCH-03**: Offscreen document provides an isolated DOM/Canvas execution environment for media decoding and encoding without service worker DOM limitations.

## Tasks

### 1. Implement Typed Storage Utilities (`src/utils/storage.ts`)
- Define default extension settings:
  ```typescript
  export const DEFAULT_SETTINGS: ExtensionSettings = {
    enabledFormats: ['png', 'jpeg', 'webp', 'avif', 'bmp', 'gif', 'ico', 'pdf', 'svg'],
    defaultFormat: 'png',
    jpegQuality: 0.92,
    webpQuality: 0.90,
    avifQuality: 0.85,
    backgroundColor: '#FFFFFF',
    filenameTemplate: '[name].[ext]',
    shortcutModifier: 'alt'
  };
  ```
- Implement `getSettings(): Promise<ExtensionSettings>` with fallback to `DEFAULT_SETTINGS`.
- Implement `saveSettings(partial: Partial<ExtensionSettings>): Promise<ExtensionSettings>`.
- Implement `onSettingsChanged(callback: (settings: ExtensionSettings) => void): () => void` listener.

### 2. Implement Typed IPC Messaging Layer (`src/utils/messaging.ts`)
- Create strongly-typed RPC abstraction around `chrome.runtime.sendMessage` and `chrome.runtime.onMessage`:
  - `sendToOffscreen<TReq, TRes>(message: TReq, timeoutMs?: number): Promise<TRes>`
  - `sendToBackground<TReq, TRes>(message: TReq, timeoutMs?: number): Promise<TRes>`
  - `sendToTab<TReq, TRes>(tabId: number, message: TReq, timeoutMs?: number): Promise<TRes>`
- Implement request correlation IDs (`id: string`) to match asynchronous responses accurately.
- Add timeout error handling (default 10s) to prevent dangling promises when a receiver drops.
- Implement structured error serialization so errors thrown in the offscreen document propagate cleanly to caller.

### 3. Implement Offscreen Document Manager (`src/background/offscreen-manager.ts`)
- Implement `ensureOffscreenDocument(): Promise<void>`:
  - Check `chrome.offscreen.hasDocument()` (available in Chromium 116+).
  - Fallback check for active offscreen contexts via `chrome.runtime.getContexts()` where available.
  - If no document exists, call `chrome.offscreen.createDocument({ url: 'offscreen.html', reasons: [chrome.offscreen.Reason.BLOBS, chrome.offscreen.Reason.DOM_SCRAPING], justification: 'Convert image formats using HTML5 Canvas' })`.
  - Mutex lock: Handle concurrent conversion requests using a shared initialization promise to prevent `chrome.offscreen.createDocument` race condition collisions.
- Implement `closeOffscreenDocument(): Promise<void>` when extension enters idle state (optional timeout after inactivity).

### 4. Implement Offscreen Document Environment (`src/offscreen/offscreen.html` & `src/offscreen/offscreen.ts`)
- HTML template hosting canvas elements and loading `offscreen.ts`.
- `offscreen.ts` entry initializing `chrome.runtime.onMessage` listener:
  - Responds to `'OFFSCREEN_PING'` with `{ type: 'OFFSCREEN_PONG', timestamp: Date.now() }`.
  - Stub handler for `'CONVERT_IMAGE_REQUEST'` (ready for Phase 2 conversion pipeline).
  - Diagnostic logging in dev mode.

### 5. Implement Background Service Worker (`src/background/service-worker.ts`)
- Initialize `chrome.runtime.onInstalled`:
  - Seed default settings in `chrome.storage.sync` if not already present.
  - Setup offscreen document check.
- Initialize `chrome.runtime.onStartup`:
  - Re-verify configuration and offscreen state.
- Implement central message dispatcher in service worker:
  - Route conversion and inspection requests between popup, content scripts, and offscreen document.
  - Handle background fetch requests to retrieve remote image blobs with extension CORS bypass privileges.

### 6. Write Comprehensive Tests (`tests/messaging.test.ts`, `tests/offscreen-manager.test.ts`)
- Mock Chrome Extension APIs (`chrome.runtime`, `chrome.offscreen`, `chrome.storage`).
- Test storage getter/setter and default merging.
- Test messaging RPC request/response cycle, correlation IDs, and timeout handling.
- Test offscreen manager mutex handling during concurrent calls.

## Verification
- Run `npm run test` and verify 100% of unit tests pass.
- Run `npm run build` to verify clean build of background service worker and offscreen document.
- Verify `dist/offscreen.html` loads correctly in an isolated Chromium context.
- Verify that sending `OFFSCREEN_PING` from the service worker returns `OFFSCREEN_PONG` with timestamp.
