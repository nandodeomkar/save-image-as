# Plan 04-01: Filename Template Engine & Sanitizer

## Objective
Enhance the filename formatting engine to support rich token interpolation (`[name]`, `[ext]`, `[page-title]`, `[domain]`, `[date]`, `[timestamp]`), multi-platform filesystem sanitization (including Windows reserved device names like CON, PRN, AUX, NUL, COM1-9, LPT1-9), length truncation with extension preservation, and a preview generator for the settings UI.

## Requirements Addressed
- **FILE-01**: Customizable filename template engine supporting tokens: `[name]`, `[ext]`, `[page-title]`, `[domain]`, `[date]`, `[timestamp]`.
- **FILE-02**: Automatic sanitization of invalid filesystem characters (`/ \ : * ? " < > |`) and filename length truncation.

## Tasks
1. Enhance `src/utils/filename-helper.ts`:
   - Add comprehensive sanitization including Windows reserved filenames (`CON`, `PRN`, `AUX`, `NUL`, `COM1`-`COM9`, `LPT1`-`LPT9`).
   - Ensure clean base name extraction from query strings, hash fragments, data URLs, and decoded paths.
   - Support token placeholders case-insensitively (`[NAME]`, `[Ext]`, `[page-title]`, `[Domain]`, `[Date]`, `[Timestamp]`, `[dimensions]`, `[width]`, `[height]`).
   - Implement `previewFilename(template: string, sampleMetadata?: Partial<InspectElementResult>, targetFormat?: ImageFormat): string` for live popup preview.
   - Implement maximum path/filename length safety (truncating base name while strictly preserving extension).
2. Expand `tests/filename-helper.test.ts`:
   - Test Windows reserved names handling (`con.png` -> `con-image.png`).
   - Test token interpolation with mixed case and all standard tokens.
   - Test extreme length truncation preserving extension.
   - Test live preview generation with mock and default metadata.

## Verification
- `npm test` runs and all filename helper tests pass.
- `npm run typecheck` passes cleanly.
