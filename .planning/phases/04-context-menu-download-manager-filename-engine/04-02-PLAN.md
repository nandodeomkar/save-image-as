# Plan 04-02: Dynamic Context Menu Manager, Storage Sync Rebuilding & Download Dispatcher

## Objective
Implement dynamic context menu registration and event routing for all enabled image formats, synchronize menus whenever settings change via `chrome.storage.onChanged`, request element inspection metadata from the active tab on right-click actions, convert the image via the offscreen worker, and dispatch direct downloads with `chrome.downloads.download()`.

## Requirements Addressed
- **MENU-01**: Right-click context menu displays a "Save Image As..." sub-menu with active format options.
- **MENU-02**: Context menu items dynamically update when user toggles format visibility in popup settings.
- **FILE-03**: Direct download dispatch via `chrome.downloads.download()` to the user's browser downloads folder.

## Tasks
1. Create `src/background/context-menu-manager.ts`:
   - `buildContextMenu(settings: ExtensionSettings): Promise<void>`
   - Safely removes existing items and creates root `save-image-as-root` ("Save Image As...") with submenus for each enabled format in `settings.enabledFormats`.
   - Adds separator and `save-image-as-settings` ("⚙️ Extension Settings...") shortcut item.
   - Configures contexts (`image`, `video`, `link`, `page`) so right-clicks on CSS background containers, canvas, inline SVGs, and direct images all display the menu.
   - Handles `chrome.runtime.lastError` gracefully.
2. Integrate into `src/background/service-worker.ts`:
   - Initialize context menu on install, startup, and background worker wake-up.
   - Attach `chrome.storage.onChanged` listener to trigger `buildContextMenu` automatically when `enabledFormats` or other relevant settings change.
   - Attach `chrome.contextMenus.onClicked` listener:
     - If settings item clicked: invoke `chrome.runtime.openOptionsPage()`.
     - If format item clicked:
       1. Request `INSPECT_ELEMENT_REQUEST` from active tab via `chrome.tabs.sendMessage`.
       2. Fallback to `info.srcUrl` or `info.linkUrl` if content script returns empty or fails.
       3. Convert image using offscreen document conversion pipeline.
       4. Generate formatted filename using `formatFilename()`.
       5. Trigger direct download using `chrome.downloads.download()`.
3. Create unit & integration tests `tests/context-menu-manager.test.ts`:
   - Test context menu generation creates root and sub-items for active formats.
   - Test updating enabled formats dynamically refreshes context menus.
   - Test click handler processes format selection and dispatches download with inspected metadata.
   - Test fallback to `info.srcUrl` when content script inspection is unavailable.
